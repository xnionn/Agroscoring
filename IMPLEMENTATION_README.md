# AgroSubsidia — Прозрачная система скоринга агрогосубсидий Казахстана

## 🎯 Цель

Создать **открытую, объяснимую систему автоматического скоринга** для оценки заявок на получение агрогосубсидий в Казахстане. Система должна быть:

✅ **Основана на реальных данных** — использует исторические заявки и официальные датасеты  
✅ **Прозрачна** — каждый балл обосновывается конкретными критериями  
✅ **Справедлива** — применяет одинаковые правила ко всем заявкам  
✅ **Объяснима** — комиссия видит почему выдан именно такой балл  

---

## 📊 Система скоринга: Как это работает

### Композитный балл (0-100)

Система рассчитывает финальный балл из 3 независимых компонентов:

```
Итоговый балл = ML(50%) + Правила(30%) + Аномальность(20%)
```

| Компонент | Вес | Что проверяет | Источник |
|-----------|-----|---------------|----------|
| **ML-вероятность** | 50% | Паттерны в 150+ исторических заявках | features_data.pkl (XGBoost) |
| **Фиксированные правила** | 30% | Минимальные требования, профиль фермера, реалистичность | Конституция РК + профил + 36K+ реальных субсидий |
| **Аномальность** | 20% | Выбросы в данных (опечатки, мошенничество) | Isolation Forest ML |

### Шкала решений

- **75-100 "Приоритет"** → Рекомендуется к одобрению  
- **50-74 "Рассмотреть"** → Требует дополнительной проверки  
- **0-49 "Отклонить"** → Не соответствует требованиям

## 🚀 Быстрый старт

### 1. Окружение

```bash
cd c:\Users\Мади\Decent_Coders\Decent_Coders\platform

# Активировать venv (если есть)
.venv\Scripts\activate  

# Или использовать Python 3.13 напрямую
C:/Users/Мади/AppData/Local/Programs/Python/Python313/python.exe -m venv .venv
```

### 2. Установить зависимости

```bash
pip install -r ../requirements_platform.txt
```

### 3. Настроить .env

```bash
# Создать .env в корне (c:\Users\Мади\Decent_Coders\Decent_Coders\.env)
GROQ_API_KEY=gsk_...  # Твой Groq API ключ с https://console.groq.com
```

### 4. Запустить сервер

```bash
cd platform
uvicorn main.py --reload --host 127.0.0.1 --port 8000
```

Сервер будет доступен на **http://127.0.0.1:8000** с автоперезагрузкой на изменения.

## 🤖 LLM Объяснение (Groq)

Когда фермер или комиссия смотрит на заявку, они видят:

### С AI (Groq LLM)
```
Объяснение [AI]:
"Заявка получила 76 баллов (Приоритет). Фермер имеет 8 лет опыта в животноводстве,
что указывает на его надёжность. Текущее поголовье (25 голов) превышает запрашиваемое (50 голов),
что наводит на мысль о возможности успешного исполнения гранта. Земельная нагрузка 12.5 голов/га 
находится в пределах здоровой нормы..."
```

### Без AI (автоматический шаблон)
```
Объяснение [авто]:
"Заявка получила 76 баллов (Приоритет). Ключевые факторы успеха: 
ML вероятность (0.68), Стаж фермера, Поголовье профиля vs заявка"
```

**Как установить Groq:**
1. Зарегистрируйся на https://console.groq.com
2. Создай API ключ (бесплатно)
3. Вставь в `.env`: `GROQ_API_KEY=gsk_...`
