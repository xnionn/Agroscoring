# АгроСкоринг (Decent Coders)

Платформа для merit-based оценки заявок на агросубсидии вместо FIFO-подхода.

Система принимает заявку от фермера, рассчитывает композитный скоринг, показывает объяснение по критериям и формирует материалы для комиссии. Финальное решение остается за человеком.

## Для комиссии

Подробная рабочая инструкция для членов комиссии: `README_COMMISSION.md`

## Что обновлено в текущей версии

1. Расширен профиль хозяйства: выручка, сотрудники, структура земли, остаток аренды, инфраструктура, налоговая и кредитная дисциплина.
2. Расширена форма заявки: софинансирование, срок исполнения, документы, история прошлых субсидий, цель заявки, свободные пояснения.
3. Усилен rule-based скоринг: добавлены новые профильные и прикладные факторы поверх базовых правил.
4. Улучшены AI-пояснения: теперь доступны краткий вывод, развернутый контекст и отдельный комментарий по свободному тексту фермера.
5. Расширены отчеты HTML/JSON: включены полный контекст заявки, история субсидий, SHAP-факторы, правила и решение комиссии.
6. Интерфейс комиссии обновлен: появилась детальная модалка по каждому критерию и более удобный экспорт.
7. Для SQLite добавлена автоматическая добалка новых колонок в существующую БД при старте приложения.
8. Навбар упрощен: в шапке оставлена только текстовая надпись бренда без отдельной иконки.

## Что умеет система

1. Регистрация и вход пользователей с ролями `farmer` и `commissioner`.
2. Восстановление пароля через email-ссылку.
3. Заполнение и обновление профиля хозяйства.
4. Подача заявки с расширенным набором полей.
5. Автоматический скоринг в реальном времени.
6. Показ критериев, причин начисления баллов, SHAP-факторов и источников.
7. Ранжирование заявок и принятие решения комиссией.
8. Экспорт полного HTML- и JSON-отчета, а также отправка отчета на email.

## Архитектура

```text
Backend:  FastAPI + SQLAlchemy + SQLite
ML:       XGBoost + SHAP + Isolation Forest
Rules:    Детерминированные правила + профиль хозяйства + контекст заявки
Frontend: HTML/CSS/Vanilla JS
LLM:      Groq (опционально) для русскоязычных объяснений
```

Итоговый балл:

```text
Composite = ML (50%) + Rules (30%) + Anomaly (20%)
```

## Как считается заявка

Система объединяет несколько слоев оценки:

1. ML-модель сравнивает заявку с историческими паттернами.
2. Базовые правила проверяют норматив, сумму, реалистичность и отсутствие экстремальности.
3. Профильные правила учитывают опыт, поголовье, землю, выручку, штат, инфраструктуру и финансовую дисциплину хозяйства.
4. Контекст заявки учитывает софинансирование, срок исполнения, комплект документов, историю прошлых субсидий и конкретность цели.
5. SHAP и критерии раскладывают итог на объяснимые факторы.
6. LLM-слой формирует короткое и развернутое текстовое объяснение без изменения итогового балла.

## Требования

1. Python 3.11+.
2. Зависимости из `requirements_platform.txt`.
3. Опционально: `GROQ_API_KEY` для AI-объяснений.
4. Опционально: SMTP-настройки для восстановления пароля и отправки отчетов на email.

## Установка

Из корня проекта:

```bash
pip install -r requirements_platform.txt
```

Если хотите использовать LLM-объяснения:

```bash
pip install groq python-dotenv
```

## Переменные окружения

Файл `.env` в корне проекта:

```env
GROQ_API_KEY=your_groq_key_here

# Ниже опционально, если нужна отправка писем
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your_email@example.com
SMTP_PASSWORD=your_password
SMTP_FROM=your_email@example.com
SMTP_USE_TLS=true
```

Если `GROQ_API_KEY` отсутствует, система переключается на шаблонные объяснения.

## Запуск

```bash
cd platform
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Основные страницы:

1. `http://127.0.0.1:8000/` - главная страница.
2. `http://127.0.0.1:8000/auth` - вход, регистрация и восстановление пароля.
3. `http://127.0.0.1:8000/portal` - портал фермера.
4. `http://127.0.0.1:8000/dashboard` - дашборд комиссии.

При старте приложение:

1. создает таблицы;
2. добавляет недостающие колонки в SQLite-схему;
3. загружает скоринг-сервис;
4. подсевает демо-заявки для дашборда.

## Как использовать

### Фермер

1. Зарегистрироваться под ролью `farmer`.
2. Заполнить профиль хозяйства.
3. Создать заявку с расширенными полями.
4. Сразу получить:
	итоговый балл,
	tier,
	критерии,
	краткое объяснение,
	развернутое NLP-пояснение,
	комментарий AI по свободному тексту,
	источники.
5. При необходимости скачать отчет или отправить его на email.

### Комиссия

1. Войти под ролью `commissioner`.
2. Открыть список заявок с фильтрами и ранжированием.
3. Из карточки заявки просмотреть:
	компоненты скоринга,
	критерии с начислением баллов,
	отдельную модалку деталей критерия,
	SHAP-факторы,
	краткое и развернутое объяснение,
	источники,
	экспортный отчет.
4. Принять решение: `approved`, `rejected` или `more_info`.

## Экспорт отчетов

В отчетах есть:

1. итоговый score и tier;
2. ML/Rules/Anomaly компоненты;
3. краткое и развернутое объяснение;
4. комментарий по дополнительным пояснениям фермера;
5. полный контекст заявки и история субсидий;
6. базовые правила;
7. SHAP-факторы;
8. решение комиссии.

## Частые проблемы

1. Нет AI-объяснений.
	Проверьте `GROQ_API_KEY` и доступность пакета `groq`.
2. Письма не отправляются.
	Проверьте SMTP-переменные в `.env`.
3. После обновления модели БД не совпадает со схемой.
	Перезапустите сервер: при старте SQLite-схема добирается автоматически.
4. UI не открывается.
	Убедитесь, что сервер поднят на `127.0.0.1:8000`.
